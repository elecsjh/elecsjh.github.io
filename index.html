RUNG 01

프로젝트 개요

물류·생산 현장에서 반복되는 이송 공정을 PLC로 자동화하는 소규모 컨베이어 시스템을 구현합니다. 목적, 배경, 핵심 사양을 정리했습니다.

목적
공정 자동화
센서로 물체를 감지하고 PLC 래더 로직으로 컨베이어 모터를 자동 구동/정지시키는 제어 시스템 구현
배경 / 필요성
전공 실습 연계
전기과 교과에서 배운 PLC 프로그래밍 이론을 실제 하드웨어 시스템으로 확장 적용
결과물
시연 + 웹 게시
실물 컨베이어 시연과 3D 모델링(X3DOM/Three.js)을 홈페이지 형태로 정리해 공개
스펙 카드의 수치(사용 PLC 모델, 벨트 속도, 센서 종류 등)는 실제 설계값이 확정되면 .spec-card .value 텍스트를 교체해 채워 넣으세요.
RUNG 02

시스템 구성

하드웨어 구성 요소와 신호 흐름을 정리합니다. 왼쪽은 구성 요소별 역할, 오른쪽은 실제 하드웨어 배치도(사진/도면)를 넣는 자리입니다.

INPUT

감지 센서

포토센서 / 근접센서로 컨베이어 위 물체 위치를 감지하여 PLC 입력 접점으로 전달

CONTROL

PLC 제어기

입력 신호에 따라 래더 로직을 실행, 모터 구동 릴레이 출력을 결정

OUTPUT

모터 / 릴레이

PLC 출력 신호를 받아 컨베이어 구동 모터를 ON/OFF 또는 정/역 제어

MECHANICAL

컨베이어 프레임

벨트, 롤러, 모터 마운트로 구성된 이송 구조물

HMI

상태 표시

운전/정지 상태를 표시하는 인디케이터 또는 소형 디스플레이

HARDWARE LAYOUT — 실제 배치도/사진 삽입 위치

RUNG 03

3D 모델링 — X3DOM

X3D 씬 그래프로 컨베이어 구조를 표현하고, TimeSensor와 PositionInterpolator로 제품 이동을 애니메이션화했습니다. 아래는 자리표시(placeholder) 모델입니다.

X3DOM VIEWER — 마우스로 드래그 시 회전
PositionInterpolator · cycle 4s · loop
실제 설계 모델(예: SolidWorks/Fusion360)을 완성하면 <box>, <cylinder> 프리미티브를 <Inline url="model.x3d"> 로 교체해 내보낸 X3D 파일을 불러오세요.
RUNG 04

3D 모델링 — Three.js

WebGL 기반 인터랙티브 뷰어입니다. 롤러 회전, 벨트 위 제품 이동을 실시간 애니메이션으로 표현하고 마우스로 자유롭게 회전/확대할 수 있습니다.

THREE.JS VIEWER — 드래그: 회전 · 휠: 확대/축소
현재는 기하학적 프리미티브로 구성된 자리표시 모델입니다. 실제 모델을 만들면 GLTFLoader로 .glb 파일을 불러와 scene.add(model) 위치에 추가하세요.
RUNG 05

기대효과 및 향후 계획

전공 이론의 실제 구현

웹 기반 결과 공유

X3DOM/Three.js를 통해 원격에서도 시스템 구조와 동작을 직관적으로 확인할 수 있습니다.

확장 가능성

센서 종류 추가, 분류(소팅) 기능, HMI 연동 등으로 시스템을 단계적으로 확장할 수 있습니다.

추후 보완 사항

실측 데이터 기반 PLC 파라미터 튜닝, 실제 3D 모델 파일 교체, 고장 대응 로직 보강 예정.
