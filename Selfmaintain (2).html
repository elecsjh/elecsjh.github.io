자기유지 기동·정지 회로

푸시버튼과 전자접촉기를 이용해 기동·정지 회로를 구성하고 표시등의 동작을 확인합니다.

1. 동작 시뮬레이터 직접 눌러보기

정지 상태 — 전자접촉기 코일 무여자

START를 누르면 MC 코일이 여자되고, MC의 보조 a접점이 닫혀 START 버튼을 놓아도 전류가 계속 흐릅니다.

2. 핵심 학습 포인트

  1. 정지 버튼(STOP)은 b접점(NC)입니다. 평상시 닫혀 있고 누르면 열려 제어회로를 끊습니다.
  2. 기동 버튼(START)은 a접점(NO)입니다. 평상시 열려 있고 누르는 순간 닫혀 코일에 전원을 공급합니다.
  3. 전자접촉기(MC)의 보조 a접점을 START 버튼과 병렬로 연결합니다. 이것이 자기유지 경로입니다.
  4. START에서 손을 떼면 START 접점은 다시 열리지만, MC 보조접점이 닫혀 있어 코일은 계속 여자 상태를 유지합니다.
  5. STOP을 누르면 직렬 회로가 끊기고 MC 코일이 소자되어 보조접점과 운전 표시등이 함께 꺼집니다.
가장 중요한 원리: START 버튼은 처음 한 번만 전류를 흘려주고, 이후에는 전자접촉기 자신의 보조 a접점이 전류 통로를 대신 유지합니다.

5. 실습 순서

  1. 전원을 차단하고 무전압 상태를 확인한 뒤, 실습 모듈의 정격 전압과 단자 번호를 확인합니다.
  2. STOP b접점을 제어전원과 START·MC 코일 사이에 직렬로 배치합니다.
  3. START a접점과 MC 보조 a접점(예: 13-14)을 서로 병렬로 연결합니다.
  4. 병렬 회로의 출력은 MC 코일 A1에 연결하고 A2는 제어전원 귀선에 연결합니다.
  5. 운전 표시등은 MC의 별도 보조 a접점을 이용해 MC가 여자될 때 켜지도록 구성합니다. 표시등 정격 전압을 반드시 확인합니다.
  6. 지도교사 확인 후 전원을 투입합니다. START를 짧게 눌러 기동, 손을 떼어 유지, STOP을 눌러 정지되는지 확인합니다.
